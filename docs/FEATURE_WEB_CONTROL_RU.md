# Web-управление

NetStitch может открыть web-интерфейс для управления приложением с другой машины в локальной сети. Это удобно, когда NetStitch запущен на одном ПК, а наблюдать таблицы, управлять списком приложений или выполнять импорт и экспорт нужно из браузера на другом устройстве.

Web-управление не требует отдельной серверной установки: web-страница работает поверх уже запущенного NetStitch.

## Где доступно

- Интерфейс: главное окно -> переключатель `Web сервер`.
- Tray-меню: пункт `Web сервер`.
- Адрес для браузера показывается в нижней панели приложения.
- Web-страница открывается с машины, на которой доступен локальный сетевой адрес NetStitch.

## Как включить

1. Запустите NetStitch на машине, где нужно вести мониторинг.
2. Включите переключатель `Web сервер`.
3. Скопируйте адрес из нижней панели.
4. Откройте этот адрес в браузере с другого устройства в той же локальной сети.

Скопированная ссылка содержит ключ доступа после символа `#`. Этот fragment не уходит в обычный GET-запрос: web-страница передаёт ключ локальному NetStitch POST-запросом, получает cookie доступа и скрывает ключ из адресной строки. Если открыть только IP и порт без ключа, появится окно ввода ключа; сам ключ можно взять из ссылки, копируемой в футере desktop-приложения.

По умолчанию web-доступ работает через HTTPS с локальным самоподписанным сертификатом из portable storage. Браузер может показать предупреждение доверия сертификату при первом открытии.

## Что можно делать

- смотреть те же основные панели, что и в desktop-интерфейсе;
- управлять отслеживаемыми приложениями;
- работать с таблицей `Мониторинг`;
- использовать CSV-импорт и CSV-экспорт через файловую систему машины, где запущен NetStitch;
- работать с облачным импортом и экспортом через локальный runtime NetStitch.

Web-интерфейс не является отдельным облачным клиентом. Все действия идут через локально запущенный NetStitch, поэтому web-версия повторяет состояние desktop-приложения и не выполняет прямые запросы к облачному сервису.

## Важные границы

- Web-страница управляет тем же состоянием, что и desktop-приложение.
- Выбор файлов в web-интерфейсе относится к машине, где запущен NetStitch.
- Если NetStitch закрыт, web-интерфейс недоступен.
- Ключ web-доступа нужен всем браузерам, которые открывают адрес без уже выданной cookie.
- Веб-доступ предназначен для доверенной локальной сети, а не для публикации в интернет.

Включайте web-доступ только в доверенной локальной сети.
