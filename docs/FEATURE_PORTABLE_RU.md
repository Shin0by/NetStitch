# Portable-режим

Portable-сборка запускается из распакованной папки и не требует обязательной установки в систему.

NetStitch поставляется как кроссплатформенный desktop/runtime-контур: основной пользовательский сценарий поддерживает Windows и Linux, а app-коннекторы проектируются с учётом Windows, Linux и macOS.

## Где доступно

- Windows: распакованная portable-папка -> `NetStitch.exe`.
- Linux: распакованная portable-папка -> `NetStitch`.
- Linux desktop launcher: `NetStitch.desktop`.
- Пользовательские файлы portable-сборки: папки `storage/`, `apps/`, `apps/icons/`, `language/`, `config/`.

Рабочие файлы находятся рядом с приложением:

- `storage/` - локальное состояние и база наблюдений;
- `apps/` - пользовательские app-коннекторы;
- `language/` - файлы локализации интерфейса;
- `config/` - редактируемые настройки поставки.

Такой формат удобно переносить между каталогами и тестовыми средами.

## Что сохраняется рядом с приложением

- локальная база мониторинга;
- выбранный язык и настройки интерфейса;
- пользовательские app-коннекторы;
- результаты импорта, экспорта и рабочие файлы NetStitch.

Portable-режим не требует глобальной установки NetStitch. Для расширенного сетевого мониторинга на Windows могут потребоваться права администратора и локально поставленные runtime-файлы захвата трафика. На Linux используется отдельная portable-сборка с собственным launcher-файлом.
