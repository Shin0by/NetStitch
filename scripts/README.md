# Scripts Catalog

Формат записей: `что это / когда брать / важные входы или артефакты`

- `scripts/dev_check.ps1` / запускать для базовой локальной проверки Rust workspace / выполняет `cargo fmt --check`, backend `cargo check`, делегирует тестовый batch в `tests/run.ps1 -Suite dev` и отдельно запускает `cargo check` для Dioxus UI через isolated target dir; по умолчанию использует последние 20 логических CPU через process affinity и оставляет первые свободными
- `scripts/check_secrets.ps1` / запускать перед commit/release и автоматически через `dev_check.ps1` / проверяет tracked и неignored untracked text files на high-confidence secret patterns: private key blocks, GitHub/GitLab/Slack/OpenAI/AWS token formats; binary/build/local ignored files не сканируются
- `scripts/check_cloud_worker.ps1` / запускать после правок `src/netstitch-cloud-worker` / выполняет `node --check src\worker.js` через project-local `.local\nodejs\node.exe`, если он есть, без deploy и без сетевых запросов
- `scripts/check_cloud_config.ps1` / запускать перед Cloudflare deploy или на новом ПК после `wrangler login` / проверяет `src\netstitch-cloud-worker\wrangler.local.toml`, D1 binding `DB`, Google OAuth vars и наличие обязательных Cloudflare Worker secret names без вывода secret values
- `scripts/load_cloudflare_env.ps1` / запускать перед локальными `wrangler` checks/deploy на новом ПК / загружает ignored `.env.cloudflare.local` в текущий PowerShell-процесс без вывода secret values
- `scripts/clear_cloud_database.ps1 -Scope AppData -Yes` / выполнять только по явной operator-команде, когда нужно очистить из cloud D1 только данные приложений, портов, протоколов, доменов и observation-строки / удаляет `app_catalog`, `observations`, `observation_author_rows`, `observation_submissions`, `domain_verifications`, сохраняет users/clients/sessions/keys/authors/auth/captcha/rate-limit/quota/audit/schema metadata; `-Scope All -Yes` или старый `-Yes` выполняет полный client-origin reset
- `scripts/compile.ps1` / canonical action для пользовательских команд `компиль`, `компилируй`, `билди`, `деплой` / запускает `dev_check.ps1`, затем `package_portable.ps1`, чтобы после каждой компиляции обновить `dist\NetStitch-win64-portable`, и создаёт Windows zip portable в `dist\release-assets` без повторного package/revision bump; принимает `-WinDivertDir`
- `scripts/update_release_version.ps1` / запускать перед release commit/push после локального тестирования portable-сборки / читает `dist\NetStitch-win64-portable\config\version-manifest.json`, берёт `modules.app.full_version` и обновляет tracked `config\release-version.json`, чтобы GitHub Release получил ту же версию, которую пользователь проверял локально
- `scripts/package_portable.ps1` / собирать локальную core portable-папку для ручного тестирования или release staging / перед сборкой проверяет, что target `NetStitch.exe` не запущен, чистит root portable-папки от устаревших publish-файлов, затем собирает core workspace, копирует `NetStitch.exe`, native runtime libraries в `libs\`, WinDivert runtime в корень portable-папки, `resources\connectors\apps` как редактируемую папку `apps\`, а connector icons как `apps\icons`, удаляет legacy `apps\*.toml`, обновляет shipped `.app` и `.svg` без удаления пользовательских `.app/.svg/.png`, при этом shipped connector docs кладёт как `apps\README_RU.txt` и `README_EN.txt`, создаёт portable `resources\netstitch.png` для информационной картинки и `resources\shin0by.png` для app icon source, создаёт portable `storage\exports`, ставит marker `storage\clear-system-events-on-next-start` для очистки только `system_events` при следующем запуске, удаляет устаревший `storage\icons`, удаляет только известные старые SDK/test integration folders `hello-world-rust`, `hello-world-cpp`, `ui-entity-showcase`, копирует найденные WinDivert runtime-файлы в корень `dist\NetStitch-win64-portable`, и записывает `config\version-manifest.json` с full-version `major.minor.patch.revision` для app/native runtime artifacts; внешние integration-модули не входят в core package по умолчанию и собираются/синхронизируются только при `-PackageModules <id>` или `NETSTITCH__PACKAGE_MODULES` (`*` явно включает все repo-local modules), с выбором `library_paths` по текущей ОС/архитектуре или через `-IntegrationTargetOs`/`-IntegrationTargetArch`, при этом их `module.json`, native library, `assets/` и module-owned `locales/` копируются внутрь папки соответствующего модуля; для UDP/QUIC packaging принимает `NETSTITCH__WINDIVERT_DIR`, `NETSTITCH__WINDIVERT_DLL` или `-WinDivertDir`, а если они не заданы, использует tracked fallback `resources\runtime\windivert\windows-x86_64`; `-TargetDir target-release-verify` позволяет проверить сборку, если основной `target\release` занят
- `scripts/package_portable_linux.sh` / собирать Linux core portable-папку для WSL/Linux GUI smoke и будущего Linux release staging / запускается из Linux/WSL, собирает root workspace в отдельный `target/linux-portable`, копирует `NetStitch`, native runtime `.so` в `libs/`, `apps/`, `apps/icons/`, `language/`, `storage/exports`, marker `storage/clear-system-events-on-next-start` для очистки только `system_events` при следующем запуске, `resources/netstitch.png` для информационной картинки, `resources/shin0by.png` для app icon source, `NetStitch.desktop` и `install-desktop-launcher.sh`, удаляет только известные старые SDK/test integration folders `hello-world-rust`, `hello-world-cpp`, `ui-entity-showcase`; included launcher installer supports `--copy-to ~/.local/opt/netstitch` for non-Debian user-local installs and reports missing GTK/WebKit/runtime libraries with distro package-name hints; external integration modules не входят в core package по умолчанию и добавляются только через `--package-modules <id>` или `NETSTITCH__PACKAGE_MODULES` (`*` явно включает все repo-local modules), при этом module-owned workspaces собираются в `integrations/<module>/target/linux-portable`, а `module.json`, native library, `assets/` и module-owned `locales/` синхронизируются внутрь папки соответствующего модуля; revision берётся из `NETSTITCH__PACKAGE_REVISION`, затем из `dist/NetStitch-win64-portable/config/version-manifest.json`, иначе из локального Linux-счётчика; по умолчанию staging лежит в `dist/NetStitch-linux64-portable`, есть `--skip-build`, `--output-dir`, `--jobs`, `NETSTITCH__LINUX_CARGO_TARGET_DIR`
- `scripts/package_linux_deb.sh` / собирать installable Linux `.deb` для проверки реального install flow в `NetStitch-Linux-Test` или Debian/Ubuntu-подобной системе / вызывает `package_portable_linux.sh`, затем собирает `dist/release-assets/netstitch_<version>_amd64.deb` с read-only runtime в `/opt/netstitch`, wrapper `/usr/bin/netstitch`, launcher `/usr/share/applications/netstitch.desktop`, иконкой `resources/shin0by.png` и зависимостями `libwebkit2gtk-4.1-0`, GTK3, AppIndicator, xdo, OpenSSL, SQLite, `ca-certificates`, `xdg-utils`; wrapper перед запуском использует user-local `~/.local/share/netstitch` для `NETSTITCH__DATA_DIR`, editable connector manifests и module runtime data; принимает `--version`, `--portable-dir`, `--release-dir`, `--skip-build`, `--jobs`, `--package-modules`, `--architecture`
- `scripts/package_module_sdk_examples.ps1` / пересобирать готовые архивы SDK-примеров после изменения `docs/module-sdk/examples/*` или Module SDK UI contract / собирает Rust и C++ варианты `UI Entity Showcase` для Windows и Linux, Linux-часть выполняет только через WSL `NetStitch-Linux-Test`, а итоговые installable zip с `module.json`, `locales/`, `bin/` и исходниками пишет в `docs/module-sdk/packages/`
- `scripts/install_module_sdk_examples_to_portable.ps1` / обновлять локально установленные showcase-модули после `scripts/package_module_sdk_examples.ps1` для ручной проверки UI / распаковывает `docs\module-sdk\packages\ui-entity-showcase-*-windows-x86_64.zip` в `dist\NetStitch-win64-portable\integrations`, сохраняет module-owned `data\`, останавливается, если NetStitch запущен из этой portable-папки; принимает `-PortableDir`, `-PackagesDir`, `-StageDir`, `-Platform`
- `scripts/package_release_assets.ps1` / собирать Windows zip-артефакты portable-релиза или CI packaging smoke / вызывает `package_portable.ps1`, чистит `dist\release-assets` или заданный `-ReleaseDir`, делает временную staging-копию portable-папки и только в ней пересинхронизирует shipped `apps\*.app` и `apps\icons\*.svg` без пользовательских коннекторов/runtime-кэша, удаляет runtime `storage` и `integrations\<module>\data` из staging-копии, оставляет только `storage\exports`, сохраняет module-owned `locales/`, создаёт `NetStitch-win64-portable-<version>.zip` с папкой `NetStitch-win64-portable\` в корне архива; если `-Version` не передан, берёт `modules.app.full_version` из portable `config\version-manifest.json`, принимает `-Version`, `-PortableDir`, `-ReleaseDir`, `-WinDivertDir`, `-SkipPackage`, `-SkipBuild`
- `scripts/package_release_assets_linux.sh` / собирать Linux tar.gz portable-релиза или GitHub release asset / вызывает `package_portable_linux.sh`, делает временную staging-копию portable-папки и только в ней пересинхронизирует shipped `apps/*.app` и `apps/icons/*.svg` без пользовательских коннекторов/runtime-кэша, удаляет runtime `storage` и `integrations/<module>/data` из staging-копии, оставляет только `storage/exports`, сохраняет module-owned `locales/`, создаёт `NetStitch-linux64-portable-<version>.tar.gz` с папкой `NetStitch-linux64-portable/` в корне архива; если `--version` не передан, берёт `modules.app.full_version` из Linux portable manifest, принимает `--portable-dir`, `--release-dir`, `--skip-build`, `--jobs`
- `.github/workflows/release.yml` / автосборка portable-архивов и Linux `.deb` при push в ветку `release` и ручной `workflow_dispatch` / берёт базовую версию из `[workspace.package].version` в `Cargo.toml`, берёт full-version из tracked `config\release-version.json`, передаёт один `NETSTITCH__PACKAGE_REVISION` в Windows/Linux portable packaging, проверяет архивы/packages на отсутствие runtime SQLite/user connector cache/module data и публикует GitHub Release для release deploy; git tag fallback используется только если release-version file отсутствует
- `scripts/setup_github_push.ps1` / настраивать project-specific GitHub SSH push contour для `origin/development` и release workflow / создаёт отдельный deploy key `~/.ssh/netstitch_github_deploy`, подтягивает official GitHub host keys из `https://api.github.com/meta` в `known_hosts`, ставит repo-local `git config core.sshCommand` с `IdentitiesOnly=yes` и умеет печатать public key для GitHub Deploy key; `-UseHttpsPort443` включает fallback через `ssh.github.com:443`, `-TestGitHub` проверяет auth path
- `scripts/wrangler.ps1` / запускать project-local Cloudflare Wrangler для Worker/D1 задач без глобального Node.js/PATH / ожидает portable Node.js в ignored `.local\nodejs` и Wrangler в ignored `.local\wrangler`, перенаправляет Wrangler config/cache/logs в `.local\xdg-*`; примеры: `scripts\wrangler.ps1 --version`, `scripts\wrangler.ps1 login`, `scripts\wrangler.ps1 d1 list`, `scripts\wrangler.ps1 secret list`; Cloudflare API tokens, OAuth client secrets и private keys держать только в ignored local contour или Cloudflare secrets, не в git
- `scripts/run_ui.ps1` / запускать Dioxus Desktop UI из workspace / принимает необязательные дополнительные аргументы для `cargo run`
- `scripts/compare_main_window_visual.ps1` / запускать после правок desktop/browser layout, header/footer, панелей, таблицы `Monitoring`, clear-кнопок или help-иконок / снимает desktop screenshot главного окна, browser-shell screenshot по локальному URL, сохраняет browser DOM dump, режет артефакты на `header`, `top-panels`, `monitoring`, `footer`, строит diff PNG по каждому региону и пишет `summary.json` в `temp\visual-debug\main-window\<timestamp>\`; требует включённый web server и установленный Microsoft Edge`
- `scripts/wsl_memory_status.sh` / использовать после `push`, когда нужно вернуть стандартный блок по памяти / требует Linux или WSL с командой `free`

- `scripts/sign_windows.ps1` / подписывать project-owned Windows `.exe` и native `.dll` для локальной development-проверки / читает ignored `config/signing.local.toml`, поддерживает только `method = "test_certificate"` на текущем этапе, подписывает `NetStitch.exe` и project-owned native libraries, не переподписывает WinDivert; `-EnsureTrustedForCurrentUser` отдельно доверяет test-сертификату в CurrentUser stores

Остальные canonical project entrypoints будут добавляться сюда по мере появления runtime и release automation.
